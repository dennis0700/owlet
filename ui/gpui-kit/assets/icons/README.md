# Icons

Carried over from the deleted Tauri bundle (`ui/src-tauri/icons/`) during the
FEAT-003 cleanup. The `owlet-gpui` binary does not consume these yet: gpui-kit
has no `.app`/`.dmg` bundling step, so there is nowhere to wire an app icon
into today. Kept here (instead of being deleted) so a future packaging step
has them on hand. The repository's other icon, `/owlet.icns` at the repo
root, is unrelated to this directory and is not duplicated here.
